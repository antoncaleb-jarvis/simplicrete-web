# simplicrete-web

Website for **Simplicrete** (simplicrete.co.za) - a new business: **installers /
applicators of decorative concrete finishes**. Not a product seller - the
contractor that does the work.

Same setup as `aap-web`: static site, private repo, deploy on Netlify.

## The business

Simplicrete installs finishes from the **MCC** product range
(`mccsa.co.za` - Masonry Cement Composites, Cape Town manufacturer). Core systems:

- **Microcement / SL Marble** - seamless pigmented cement finish, ~2-3mm, over
  tiles/screed/concrete. Floors, walls, showers, stairs, countertops.
- **Stone Carpet** - bound natural-stone overlay. Patios, pool surrounds,
  driveways, pathways. Slip-resistant, permeable options.
- **Epoxy & resin floors** - high-build systems for garages, workshops,
  showrooms, retail. Solids or decorative flake/metallic.
- **Concrete resurfacing** - self-levelling overlays over tired/uneven concrete.

MCC tagline: "Be Different - Be Original". Simplicrete's own voice is written
fresh (plain, confident, not salesy).
